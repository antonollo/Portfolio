# Styles (`frontend/src/styles`)

## Finalidade
Concentrar os arquivos de estilização global da aplicação, as diretivas do **TailwindCSS** e os tokens de design/temas utilizados pelos componentes **shadcn/ui**.

## Conteúdo Armazenado
- Folha de estilos global (ex.: `globals.css`) com diretivas do TailwindCSS;
- Variáveis CSS (design tokens) de cores, bordas, tipografia e suporte a tema claro/escuro (padrão shadcn/ui);
- Animações ou utilitários CSS globais quando não cobertos pelas classes utilitárias padrão.

## Responsabilidades
- Garantir identidade visual uniforme em toda a aplicação;
- Centralizar a customização de temas e tokens em um único local, evitando sobrescritas de CSS espalhadas pelo projeto.

## Subdiretórios
Este diretório não possui subdiretórios pré-fixados. Os arquivos de estilo global devem ser mantidos diretamente aqui (por exemplo: `globals.css`, `themes.css`).
